# 🧮 Calculadora em Java

Projeto de uma calculadora simples desenvolvida em **Java**, com interação via terminal.
O objetivo deste projeto é praticar conceitos fundamentais da linguagem e organização de código utilizando **Programação Orientada a Objetos (POO)**.

---

## 📚 Sobre o projeto

Esta aplicação permite que o usuário realize operações matemáticas básicas através de um **menu interativo no terminal**.

O projeto foi desenvolvido como parte dos meus estudos em **Java**, com foco em reforçar conceitos como:

* Estruturas de controle (`while`, `switch`)
* Entrada de dados com `Scanner`
* Criação de classes e métodos
* Organização de código em projetos Java

---

## ⚙️ Funcionalidades

* ➕ Soma de dois números
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* 📋 Menu interativo no terminal
* 🔁 Execução contínua até o usuário escolher sair

---

## 🛠️ Tecnologias utilizadas

* Java
* Programação Orientada a Objetos (POO)
* Terminal / Console

---

## 📂 Estrutura do projeto

```
Calculadora/
│
├── Main.java
├── Calculadora.java
```

**Main.java**

* Responsável pelo menu do programa
* Captura as entradas do usuário
* Chama os métodos da calculadora

**Calculadora.java**

* Contém os métodos responsáveis pelas operações matemáticas

---

## ▶️ Como executar o projeto

1. Clone este repositório:

```
git clone https://github.com/regine-barbosa/calculadora-java.git
```

2. Abra o projeto em sua IDE de preferência (IntelliJ, Eclipse ou VS Code).

3. Execute o arquivo:

```
Main.java
```

4. Utilize o menu no terminal para escolher a operação desejada.
